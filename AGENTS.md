# Public release maintenance

Write public release material in English. This includes the repository description, the homepage README, release titles and notes, standalone installation guides, and descriptions and names of new assets. Preserve product names, commands, code identifiers, and legal attributions.

Use the current README when preparing a new release. Keep the homepage download links on `releases/latest` and link each release's own installation guide to its specific tag. Match the version and archive SHA-256 to the verified artifact. Keep release notes specific to the published version, and verify the English copy and the download links after publishing.

Public release copy is reviewed separately from the skill runtime and user-authored research.
